# Arquivo de versoes anteriores

Este diretorio contem copias completas das versoes antigas e os `main*.c`
que estavam espalhados pela raiz do projeto quando ele foi organizado.

- `versoes/`: diretorios historicos originais (`simulador_v05` etc.), sem alteracoes.
- `fontes_antigas/`: copias manuais antigas (`main_backup*.c`, `main_v*.c`).

As versoes antigas sao **snapshots** importados; nao representam commits historicos
anteriores ao primeiro commit no Git. Para compilar a versao atual, use o
`Makefile` da raiz. Algumas versoes antigas podem exigir assets e dependencias
especificos de sua epoca.
